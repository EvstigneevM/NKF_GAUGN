## Описание курса 

Введение в немецкую классическую философию. 
Начинаем с кантовского учения о чувственном созерцании, переходим к учениям об интеллектуальном созерцании Фихте и Шеллинга и заканчиваем критикой непосредственности Гегеля.


## Отчетность 

Экзамен, три вопроса из вопросов к занятиям (1 по Канту, 1 по Гегелю, 1 по посткантовскому идеализму)

Коллоквиум после занятия 7 по «Критике чистого разума»; студентам предлагается выбрать один из вопросов, помещенных в раздел «Задания», и подготовить емкий ответ на него. Ответ должен опираться на текст первоисточника, включать в себя реконструкцию позиции Канта, объяснение того, чем она мотивирована, и что из нее следует.
