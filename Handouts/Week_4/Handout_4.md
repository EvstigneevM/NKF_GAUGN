## 1. Структура способностей

 Представление вообще (*repraesentatio*) есть род. Ему подчинено сознательное представление, перцепция (*receptio*). Ощущение (*sensatio*) есть перцепция, имеющая отношение исключительно к субъекту как модификация его состояния; объективная перцепция есть познание (*cognitio*). Познание есть или созерцание, или понятие (*intuitus vel conceptus*). Созерцание имеет непосредственное отношение к предмету и всегда бывает единичным, а понятие имеет отношение к предмету опосредованно, при посредстве признака, который может быть общим для нескольких вещей. (A320/376–377)

## 2. Созерцание и понятие

|                                 | Созерцания           | Понятия                   |
| ------------------------------- | -------------------- | ------------------------- |
| **Лоический критерий**          | единичные            | общие                     |
| **Феноменологический критерий** | непосредственные     | опосредованные            |
| **Мереологический критерий**    | часть и целое        | род и вид                 |
| **Способность**                 | низшая (чувственная) | высшая (интеллектуальная) |
| **Хар. способности**            | рецептивная          | спонтанная                |
| **Вклад**                       | многообразное        | единство                  |
| **Как акт**                     | → партикулярия       | → набор общих свойств     |
| **Как его содержание**          | многообразное        | единство многообразного   |

## 3. Материя и форма

|                     | Материя                 | Форма                                       |
| ------------------- | ----------------------- | ------------------------------------------- |
| **За что отвечает** | Многообразное           | Порядок                                     |
| **Источник**        | Вещь, аффектация        | Душа, восприимчивость                       |
| **Эпист. статус**   | Нельзя знать *a priori* | Можно знать *a priori* (некоторые свойства) |
